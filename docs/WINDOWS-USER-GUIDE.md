# Vault 443 1.3.4 для Windows

Это инструкция для локальных, неопубликованных сборок версии 1.3.4.
Текущая локальная сборка [R9](../dist/windows/validated-2026-11-07-r9/) прошла
согласованную приёмку Windows 10 22H2 и Windows 11; [итоговый отчёт](WINDOWS-ACCEPTANCE-REPORT-2026-11-07.md).
Приложение и установщик не имеют Authenticode-подписи, релиз не опубликован.

## Установка

Нужна Windows 10 22H2 x64 или Windows 11 x64. Qt, необходимые runtime-библиотеки,
VPN-движки и Wintun включены; устанавливать SDK, Go или Qt отдельно не требуется.

1. Возьмите `Vault443-1.3.4-windows-x64-setup.exe` из
   выбранного каталога кандидата в [dist/windows](../dist/windows/).
2. Сверьте файл с `SHA256SUMS` из того же каталога кандидата.
   Например, в PowerShell: `Get-FileHash .\Vault443-1.3.4-windows-x64-setup.exe -Algorithm SHA256`.
3. Запустите установщик из обычного пользовательского сеанса и подтвердите UAC.
   При обычной интерактивной установке это подтверждение устанавливает службу и
   предоставляет доступ текущему пользователю.
4. Откройте Vault 443 из меню «Пуск». Служба работает от LocalSystem (SYSTEM),
   а окно — от обычного пользователя; повышать права при каждом запуске не нужно.

Если приложение установлено автоматически от SYSTEM, первый запуск может отдельно
запросить UAC для предоставления доступа. Административные настройки, включая
загрузочное подключение, также могут требовать подтверждения.

## Профили и подключение

Для основного VPN импортируйте `vless://`, `trojan://`, `ss://` или `ssconf://`,
текстовый файл либо подписку. Проверьте предварительный список и сохраните профили.
Для рабочих VPN импортируйте конфигурации WireGuard/AmneziaWG или файл OpenVPN
`.ovpn`; поддерживаемые автономные ключи `vpn://` также можно вставить при импорте.
Выберите нужный профиль, запустите подключение и дождитесь конечного состояния.
При ошибке откройте журнал соответствующего профиля.

Одновременно используется один основной VPN и несколько рабочих туннелей.
Рабочие сети и DNS-зоны направляются через соответствующий VPN. Пересекающиеся
маршруты или зоны могут потребовать выбора владельца в настройках маршрутов.
Рабочий полный туннель приостанавливает основной VPN; после его отключения
основное подключение может восстановиться.

Запуск окна при входе в Windows и подключение основного VPN при загрузке системы —
разные настройки. Для второго отдельно выберите загрузочный основной профиль.
Рабочие VPN после перезагрузки запускаются вручную; перезапуск службы в пределах
той же загрузки восстанавливает запрошенные подключения.

В общих настройках доступны русский, английский и системный язык. Закрытие окна
не отключает VPN: используйте значок в трее или повторно откройте приложение.
Для освобождения сетевой защиты явно отключите подключения в интерфейсе.

## Обновление и удаление

Для обновления запустите новый проверенный установщик поверх существующей версии.
Профили сохраняются по умолчанию; служба может перезапуститься.

Удаляйте Vault 443 через список установленных приложений Windows. Установщик
сначала штатно закрывает точный GUI через Restart Manager и проверяет его
завершение. Если окно зависло или не может закрыться, удаление прерывается до
остановки службы и сетевой очистки; принудительное завершение не применяется.
Закройте окно и повторите удаление. После закрытия GUI удаление очищает только
принадлежащие приложению сетевые ресурсы; при ошибке также прерывается и сохраняет
файлы и профили для безопасной повторной попытки.
Профили и журналы в приватном каталоге ProgramData сохраняются по умолчанию.

Рядом с установщиком находятся `build-manifest.json`, `artifact-manifest.json`
и точный `source.zip`. Состояние проверок приведено в
[отчёте приёмки](WINDOWS-ACCEPTANCE-STATUS-2026-11-06.md), технические сведения —
в [WINDOWS.md](WINDOWS.md).
